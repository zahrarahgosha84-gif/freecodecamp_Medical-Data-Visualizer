# Medical Data Visualizer

freeCodeCamp — Data Analysis with Python Certification project.

Uses Pandas, Matplotlib and Seaborn to visualize and analyze cardiovascular disease survey data: a categorical bar plot comparing good/bad habits by cardio status, and a correlation heatmap of cleaned patient data.

## Files

- `medical_data_visualizer.py` — main solution (`draw_cat_plot`, `draw_heat_map`)
- `medical_examination.csv` — dataset
- `test_module.py` — unit tests
- `main.py` — runs the visualizations

## Usage

```bash
pip install -r requirements.txt
python main.py
```
